## Design Specificity

Authored, unmistakably — mode-rewritten scoreboard title, disciplined amber, untransplantable copy voice. But the file is read front-to-back every time (Fuel 6,250px, Stack 4,500px): specificity optimized for READING the file while the surface mode is OPERATING it.
